# Bookmarks Manager

Инструмент для синхронизации закладок Chrome между несколькими профилями.

## Зачем нужен

Если у вас несколько профилей Chrome (например, личный, учебный, рабочий) - в каждом
есть как уникальные папки закладок, так и общие (например, Tools, Important).
Bookmarks Manager находит расхождения в общих папках и помогает привести их
к единому актуальному состоянию - без ручного копирования.

## Как работает

1. Вы экспортируете закладки из каждого профиля Chrome в HTML (Ctrl+Shift+O → «Экспортировать закладки»)
2. Кладёте файлы в папку `bookmarks/`
3. Настраиваете `config.json` - указываете пути к файлам и имена общих папок
4. Запускаете скрипт - он находит расхождения и предлагает решения по каждому:
   - **д** - добавить закладку/папку во все профили, где её нет
   - **у** - удалить закладку/папку из всех профилей
   - **п** - пропустить (оставить как есть)
5. Скрипт создаёт бэкапы и записывает обновлённые файлы

## Установка и запуск

```bash
uv venv .venv
source .venv/Scripts/activate
uv pip install -r requirements.txt
```

Настройте `config.json` под свои профили.

```bash
python main.py
```

Проверка кода:

```bash
ruff check .
ruff format --check .
pyright .
```
